# PrintPilot Dokumentation

## Zweck

Diese Dokumentation ist der Einstiegspunkt für die weitere Entwicklung von PrintPilot und ersetzt die vielen einzelnen Zwischenstands-Dateien durch eine konsolidierte Struktur.

## Hauptdateien

```text
README.md
PROJECT_STATE.md
ARCHITECTURE.md
UI_STANDARDS.md
WORKFLOWS.md
OUTPUT_SYSTEM.md
BACKUP.md
ROADMAP.md
DOCS_CLEANUP.md
```

## Für einen neuen Chat

Für einen neuen Chat reichen zunächst:

```text
docs/README.md
docs/PROJECT_STATE.md
docs/ROADMAP.md
docs/ARCHITECTURE.md
docs/UI_STANDARDS.md
docs/WORKFLOWS.md
docs/OUTPUT_SYSTEM.md
```

## Arbeitsweise

```text
1. kleine Schritte
2. vollständige betroffene Dateien bereitstellen
3. Einzeldateien zuerst, Gesamtpaket zuletzt
4. lokal ersetzen
5. npm run build
6. npm run dev
7. testen
8. committen
9. pushen
```
