# UI Standards

Stand: 14.05.2026

## DetailDrawer

Der DetailDrawer wird per React Portal in `document.body` gerendert.

Standard:

```txt
fixed rechts
z-index 1000/1001
Overlay über der App
Content scrollt intern
Footer bleibt unten
keine Abhängigkeit von externer CSS-Datei für kritische Positionierung
```
